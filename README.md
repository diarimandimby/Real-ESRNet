# Real-ESRNet

## Aperçu
Implémentation du modèle de super-résolution Real-ESRNet (décrit dans l'article *Real-ESRGAN: Training Real-World Blind Super-Resolution
with Pure Synthetic Data*) avec PyTorch. L'image à gauche constitue une image à basse résolution et celle de droite constitue une image de haute résolution générée par le modèle.
