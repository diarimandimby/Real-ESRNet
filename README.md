# Real-ESRNet

## Aperçu
Implémentation du modèle de super-résolution Real-ESRNet (décrit dans l'article *Real-ESRGAN: Training Real-World Blind Super-Resolution
with Pure Synthetic Data*) avec PyTorch. Les images à gauche constituent des images à basse résolution et celles de droite constituent les images de haute résolution générées par le modèle.
